# Kick-off Meeting – NovaRetail BI

**Date :** 08 septembre 2026

**Version :** V1

**Statut :** Validé

---

## 1. Contexte

NovaRetail est une entreprise spécialisée dans la distribution de produits.

Le directeur commercial souhaite disposer d'un tableau de bord Power BI lui permettant de suivre les performances commerciales de l'entreprise et d'améliorer le pilotage de son activité.

Le projet NovaRetail BI a pour objectif de construire une solution décisionnelle complète, depuis la modélisation des données jusqu'à la réalisation d'un tableau de bord interactif.

---

## 2. Objectifs du projet

Le projet vise à :

- centraliser les données de ventes ;
- concevoir une base de données décisionnelle ;
- définir les indicateurs clés de performance (KPI) ;
- produire un tableau de bord Power BI destiné au directeur commercial.

---

## 3. Questions abordées lors du Kick-off

Afin de mieux comprendre les besoins du métier, plusieurs questions ont été préparées.

### Compréhension du besoin

- Quels besoins souhaitez-vous satisfaire avec le tableau de bord ?
- Quels indicateurs utilisez-vous aujourd'hui ?
- Qui utilisera le tableau de bord ?
- Quelles décisions souhaitez-vous pouvoir prendre grâce au tableau de bord ?

### Données disponibles

- Quelles sont les sources de données ?
- À quelle fréquence les données sont-elles mises à jour ?
- Quel outil utilisez-vous aujourd'hui pour suivre les ventes ?
- Disposez-vous des données de toutes les régions ?
- Disposez-vous de données concernant vos concurrents ?

---

## 4. Livrables attendus

À l'issue du projet, les livrables suivants seront produits :

- Modèle de données décisionnel
- Base PostgreSQL
- Requêtes SQL analytiques
- Modèle Power BI
- Tableau de bord commercial
- Documentation du projet

---

## 5. Conclusion

Le Kick-off a permis de clarifier les objectifs du projet, d'identifier les principaux besoins métier et de définir le périmètre fonctionnel de la solution décisionnelle NovaRetail BI.
