
# Database

Ce dossier contient les scripts SQL utilisés pour créer et alimenter la base de données PostgreSQL du projet NovaRetail BI.

## Contenu

- **schema.sql** : création de la structure de la base de données (tables, clés primaires, clés étrangères et contraintes).
- **seed.sql** : insertion d'un jeu de données fictif permettant de tester les requêtes SQL et le tableau de bord Power BI.

## Objectif

Cette base de données constitue la source de données du projet NovaRetail BI.

Elle est conçue selon un modèle décisionnel (Star Schema) optimisé pour l'analyse des ventes.
